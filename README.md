# Regularize or Localize

Implementation code and curated result files for **Regularize or Localize: When Training-Time KV-Cache Geometry Pays Under Quantization**. The repository supports reading the implementation and regenerating selected tables and the figures from the curated results; it is not a complete experimental reproduction.

Repository: <https://github.com/libophd/code-regularize-or-localize> · Paper: <https://openreview.net/forum?id=vPYlyHPomp>

The implementation covers language-model pretraining with Sketched Isotropic Gaussian Regularization (SIGReg), direct key/value-cache regularization, continuation and LoRA probes, simulated cache quantization, and layer-wise diagnostics.

## Quick start

Python 3.12 is the tested interpreter. Create a fresh environment from the repository root:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements/tested.txt
python -m pip install -e '.[dev]'
CUDA_VISIBLE_DEVICES='' python scripts/phase1_dry_run.py
make test
```

The dry run trains and evaluates a tiny model on synthetic data. `make test` runs the two test files in `tests/`, which pin the frozen-trunk behavior of the A2 and A3 probes that the paper's reproducibility notes cite. Neither downloads a dataset or needs a checkpoint or a GPU. Install the appropriate PyTorch build separately if a different CPU/GPU platform needs one; that is not a claim of bit-exact historical reproduction.

## Result files, tables, and figures

The result files behind the paper's tables and figures are in `paper/artifacts/`, with a SHA-256 manifest (`paper/artifacts/manifest.json`). Three generators read only these files:

```bash
make tables
```

| Command | What it regenerates |
|---|---|
| `scripts/revision/pass1_tables.py --evidence bundle` | Table 3 (main quantization table, every row as printed) and the grid cells shown in Tables 4 and 9 |
| `scripts/paper_tables.py --artifacts` | The values of Table 2 (five of its seven rows), Table 4, Table 5, and Table 10, in the layout of the first version of the paper |
| `scripts/revision/tier2_correlations.py --evidence bundle` | Table 12 (median layer-wise correlations) |

Tables 6-8 and 13 are not regenerated by a command in this repository; their result files are in `paper/artifacts/`. [Reproducibility](docs/REPRODUCIBILITY.md) has the details.

To regenerate the figures, install the optional plotting dependencies:

```bash
python -m pip install -r requirements/figures.txt
make figures
```

None of these steps reruns a model. See [Reproducibility](docs/REPRODUCIBILITY.md) for what can and cannot be reproduced from this repository.

## Layout

| Path | Contents |
|---|---|
| `src/jepa_lm/` | Models, objectives, training, quantizers, and diagnostics |
| `scripts/` | Training, evaluation, and analysis entry points; table and figure generators |
| `tests/` | The frozen-trunk and cache-capture tests cited in the paper |
| `paper/artifacts/` | Sanitized curated result files and their SHA-256 manifest |
| `requirements/` | Tested package versions and optional figure dependencies |
| `docs/` | Reproduction scope and experiment entry points |

For new training or evaluation, start with [Experiment entry points](docs/EXPERIMENTS.md). The original checkpoint binaries are not included and no download location is provided in this release. Consequently, this package currently supports code inspection, the synthetic dry run and the cited tests, and regeneration of the tables listed above and of the figures from curated measurements, not a rerun of the experiments.
